## Запуск Docker

- ДЗ2: образ Python 3.10 успішно зібраний; PostgreSQL healthcheck пройдений; `/healthchecker` виконує `SELECT 1` і повертає `Welcome to FastAPI!`. Кнопку «Перевірити БД» додатково перевірено в браузері.
- ДЗ3: контейнер працює на 3000; форма записує повідомлення в змонтовану папку `storage`.
- ДЗ6: міграція застосована на PostgreSQL 16, Faker створює 40 студентів, 3 групи, 4 викладачів, 7 предметів; усі 12 вибірок виконані. CRUD створення/читання/оновлення/видалення перевірено на окремому тестовому викладачеві. `alembic check` не знаходить розбіжностей моделей і схеми.
- ДЗ8: CRUD перевірено через HTTP на справжньому PostgreSQL.
- ДЗ10/12: перевірено SMTP-доставку до локального Mailpit, підтвердження email, вхід, CRUD, Redis-авторизацію. Для ДЗ12 також перевірено одноразове скидання пароля та відхилення старого access token.

Для повторення HTTP-перевірок запустіть усі відповідні Compose-стеки й `python tools/smoke.py` (потрібен httpx). Скрипт створює тестові облікові записи та повідомлення. Контакти, створені скриптом, він видаляє після перевірки.

## Межі перевірки

Cloudinary-адаптер та збереження URL аватара перевірені з підміною зовнішнього сервісу. Реальне завантаження у Cloudinary потребує ключів власниці; без них API повертає 503. SMTP перевірено локально в Mailpit, зовнішній поштовий провайдер не налаштовано. LMS-завантаження не виконувалося. Опціональний хмарний деплой і refresh-token flow не входять до реалізації.
