# ДЗ4 — Асинхронне сортування файлів

Python 3.10+. Асинхронні шляхи AnyIO та потокове копіювання через aiofiles.

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python main.py "D:/path/source" "D:/path/sorted" --workers 8
```

Скрипт **копіює** файли рекурсивно: `image.JPG` → `jpg/image.JPG`, файл без розширення → `no_extension/`. Регістр розширення не впливає на папку. Однакові імена отримують суфікси `_1`, `_2`, … без перезапису; вихідні файли залишаються на місці. Приховані файли без суфікса також потрапляють у `no_extension`.

`read_folder` наповнює обмежену чергу, `copy_file` копіює блоками по 1 MiB. Кількість працівників — від 1 до 128. Перетин вихідної та цільової папок заборонений; символічні посилання пропускаються, щоб уникнути циклів. Помилки файлових операцій логуються, за наявності помилок код завершення ненульовий.

Тест: `python -m pip install pytest`, потім `python -m pytest -q`.
